Lesson Plan

Grade: UPK 4
Content Area: W.R.A.P. After-School · Social-Emotional Learning
Date: 10/20/26
Central Focus:

Students will name emotions confidently and sort by color (DOE observation day).

Lesson # 13 / 21
Lesson Focus and Goals:
  • Students will name each feeling in a polished read of The Color Monster.
  • Students will match emotion photo cards in the Memory Game using full sentences.
  • Students will sort pom-poms by color into the painted emotion jars with tweezers.
Resources and Materials:

Emotion photo cards (2 copies each), tweezers, pom-poms, painted emotion jars

Learning Objectives:

I can name feelings and match them to colors. I can sort pom-poms by color.

Early Learning Standard (SEL — Self-Awareness):

Children name and describe their own emotions confidently, and match feelings to the colors they learned.

TimeActivity:
7 min Introduction: Feelings check-in and The Color Monster (polished read — DOE visit day).
Teacher: Reads slowly with big expressions; pauses for children to name each feeling — they know this book now.
Students: Name every feeling before the teacher turns the page.
6 min Mini-lesson: Say it like you know it + sorting rules.
Teacher: Models a confident name: “I feel YELLOW-happy!” Then models the tweezers sort: pick up one pom-pom, drop it in the matching jar.
Students: Echo the confident voice; practice one tweezers pick-up.
14 min Activity: Emotion Memory Game + Colorful Emotion Sort.
Teacher: Sets out small groups with 2 copies of each photo card; places the painted emotion jars from Oct 1.
Students: Memory: flip two cards; “Tell me what you SEE in this picture” — full sentences encouraged. Sort: tweezers-sort pom-poms by color into the jars. Fine motor + feelings review in one.
4 min Game: Jar match.
Teacher: Holds up a pom-pom.
Students: Point to the jar it belongs in and name the feeling. First correct voice wins the round.
4 min Closure: “Point to the jar that matches how you feel RIGHT NOW.”
Students: Each child points; the class reads the room’s feelings.
Assessment:
  • Observation during the Memory Game: does the child use a full sentence to describe what they see in the picture?
  • Exit check: point to the jar that matches how you feel right now.
